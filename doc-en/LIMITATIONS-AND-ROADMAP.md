# Limitations and roadmap

Current limitations include classic OpenGL immediate mode, no default texture/material system, simple CPU lighting, AABB-only physics, no skeletal animation, no audio, no visual editor, and limited scalability.

Natural future directions are textures, a debug HUD, triggers, particles, optional audio, an in-game Lisp console, S-expression prefabs, and an optional modern renderer that does not remove the readable teaching renderer.
